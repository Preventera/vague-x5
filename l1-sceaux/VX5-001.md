# Sceau VX5-001 — Assignation temporaire

> **Statut : GABARIT NON SCELLÉ.** Le scellement exige signatures humaines et
> horodatage. Un sceau scellé ne se modifie jamais — on ouvre une nouvelle vague.

| Champ | Valeur |
|---|---|
| `sceau_id` | VX5-001 |
| `horodatage` | *à apposer au scellement* |
| `mesure_id` | 1 — Assignation temporaire d'un travail |
| **Outcome primaire** | Durée cumulée d'IRR par dossier (jours) |
| **Outcomes secondaires** | Coût imputé par dossier ; proportion de dossiers atteignant le T8 |
| **Outcomes de contrepoids** | Taux de récidive ; taux de contestation |
| **Dose** | Délai entre la lésion et l'offre d'assignation (jours) ; proportion de dossiers avec offre |
| **Strates déclarées** | (a) taille d'établissement ; (b) existence d'un poste léger disponible ; (c) délai d'offre sous/au-dessus de la médiane |
| **Devis** | Coin échelonné, 4 vagues trimestrielles, randomisation stratifiée sur (a) |
| **Unité d'analyse** | La mutuelle, pas l'établissement |
| **Puissance** | À calculer sur l'historique de dossiers. Si le n requis dépasse le bassin disponible, le déclarer **avant** et accepter un résultat non concluant |
| **Seuil de succès** | Réduction de la durée médiane d'IRR, IC excluant zéro |
| **Non concluant** | IC incluant zéro **et** n inférieur au n requis. Distinct de « pas d'effet », qui suppose une puissance atteinte |
| **Transformations L2 autorisées** | Exclusion des dossiers ouverts avant le début de la période. **Aucune imputation** |
| **Signataires** | Responsable SST + tiers analytique |

## Ordre d'exécution

1. Sceller VX5-001 — une page, signatures.
2. Constituer L0 : établissements, contexte, historique.
3. Calculer la puissance réelle. Ajuster le nombre de vagues **avant** de sceller définitivement.
4. Tirer le calendrier de vagues, stratifié.
5. Déployer. Collecter L2.
6. Analyser selon VX5-001. **Publier la fiche, quel que soit le résultat.**
7. Passer au lot suivant.
